# xuing/homebrew-tap

Homebrew formulae for [ssh-paste](https://github.com/xuing/ssh-please-paste-picture):
paste screenshots into programs that run over SSH.

```sh
brew install xuing/tap/ssh-paste
```

`Formula/ssh-paste.rb` is written by the release workflow of
xuing/ssh-please-paste-picture for each release. Do not edit it here; the next
release replaces it.
